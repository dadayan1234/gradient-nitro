# Gradient Nitro

A colorful workspace with **clear hierarchy** and *comfortable contrast*.

## Quick start

- Choose a dark or light palette.
- Enable the native rounded workspace.
- Adjust colors for your favorite languages.

Use `const radius = 12;` to explore inline code colors.

> Keep the code in focus, with a gentle accent around floating widgets.

[Explore the theme](https://github.com/dadayan1234/gradient-nitro)

```typescript
const theme = { name: "Gradient Nitro", radius: 12 };
```
